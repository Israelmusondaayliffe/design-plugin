## Adaptation rules

1. Suitable contexts: cross-platform mobile applications, and teams using web technology for native-like interfaces.
2. Preserve: mode-aware components and mobile interaction breadth.
3. Poor fit: apps requiring deeply custom platform-native controls unavailable through the component layer.

## Failure modes

1. Forcing one platform appearance everywhere.
2. Using mobile components without touch and safe-area checks.
3. Assuming component availability guarantees a coherent information architecture.
