# Microsoft Fluent 2

## Visual thesis

Fluent 2 is useful when a product must feel coherent across web, desktop, and a broad enterprise ecosystem. Its visual neutrality is supported by disciplined palette roles, compact spacing, clear typography, and adaptive layout rather than by a single signature decoration.

## Signature relationships

- **Neutral foundation plus bounded brand.** Brand color sits inside a larger semantic system.
- **Compact spacing with adaptation.** Small repeatable increments support dense work without ignoring touch requirements.
- **Readable type hierarchy.** Sentence case and stable type roles reduce interface noise.
- **Cross-platform continuity.** Components may adapt while remaining recognizably related.
- **System roles over one theme.** Light, dark, neutral, shared, and brand relationships are designed together.

## Layout and density

Start compact for high-frequency desktop work, then expand touch targets and spacing when the device or interaction mode requires it. Keep alignment, navigation hierarchy, and component roles stable across modes.

## Typography

Use a clear ramp for page title, section heading, body, caption, and control text. Sentence case supports calm operational scanning. Reserve dramatic display typography for actual narrative surfaces, not routine work areas.

## Color and surfaces

Build a neutral surface hierarchy first. Add semantic shared colors for status and feedback. Brand color should identify and emphasize, not repaint every component. Dark mode needs its own tested relationships rather than simple inversion.

## Components and interaction

Buttons, menus, navigation, inputs, dialogs, and data surfaces should share predictable focus, hover, selected, and disabled behavior. Cross-platform implementations may vary in anatomy when platform conventions demand it.

## Adaptation rules

- Preserve neutral hierarchy, semantic/shared color roles, compact spacing logic, and responsive adaptation.
- Change brand color and typography only with a complete role mapping.
- Let a product become more expressive through content and media without breaking operational controls.

## Failure modes

- Mistaking neutral styling for lack of hierarchy.
- Painting status states with brand color.
- Using desktop spacing unchanged on touch surfaces.
- Copying Microsoft visual cues into unrelated products without ecosystem or interaction continuity.
