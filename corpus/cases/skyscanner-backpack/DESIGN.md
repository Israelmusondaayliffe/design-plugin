# Skyscanner Backpack

## Visual thesis

The useful tension sits between discovery-to-decision bridge and travel media role. The preview brief makes it concrete: travel discovery image above a structured search and fare comparison rhythm.

## Signature relationships

**Discovery-to-decision bridge.** Inspiration gives way to structured search and comparison.

**Localization tolerance.** Layouts anticipate longer labels, currencies, and varied scripts.

**Cross-platform continuity.** Shared roles survive different native and web conventions.

**Brand-action discipline.** Optimistic color remains tied to selection and progress.

**Travel media role.** Photography establishes place and desire without becoming booking evidence.

## Editorial composition and proof

Wide media header narrowing into responsive task columns. Give localization tolerance enough room to work beside travel media role. Validate the arrangement with the destination's own data, copy, and controls.

## Type, color, and art direction

Apply a humanist sans hierarchy where discovery-to-decision bridge needs hierarchy. Place photography with deliberate subject, crop, and rights handling where cross-platform continuity needs proof. The destination palette must keep localization tolerance distinct from travel media role.

## Narrative behavior and access

State changes should clarify cross-platform continuity while preserving discovery-to-decision bridge. Brief state transitions for search and selection.

For the Skyscanner Backpack adaptation, pair cross-platform continuity with names, landmarks, focus, and non-color cues. Preserve discovery-to-decision bridge through keyboard, touch, reflow, and reduced motion. The failure probe is 'letting destination media push search controls below the useful first view'.

## Adaptation rules

1. Discovery-to-decision bridge is the first acceptance rule for travel discovery and booking products.
2. Preserve this condition: inspiration gives way to structured search and comparison.
3. A version for international services balancing brand media with transaction clarity must still avoid single-market utilities with no visual discovery or cross-platform pressure.

## Failure modes

**Failure 1.** Letting destination media push search controls below the useful first view.

**Failure 2.** Using brand blue for every piece of metadata and losing action hierarchy.

**Failure 3.** Designing around short English labels only.

**Failure 4.** Hiding fare or date state behind decorative animation.
