- **touch-first components.** Gestures and mobile states are built into the component model.

## Adaptation rules

- Suitable contexts: mobile web and hybrid apps needing native-like navigation, and rapid prototypes that still need coherent touch patterns.
- Preserve: platform visual modes and mobile navigation depth.
- Poor fit: products requiring a narrow bespoke interaction language with little platform resemblance.

## Failure modes

- Combining iOS and Material patterns inside one unexplained screen.
- Using every available panel and modal because the toolkit exposes it.
- Forgetting keyboard and assistive access behind touch gestures.
