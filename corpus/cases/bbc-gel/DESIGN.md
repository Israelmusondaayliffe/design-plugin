# BBC Global Experience Language

## Visual thesis

Navigation and content order support broad audiences and urgent contexts. Story prominence changes without breaking reading sequence.

## Signature relationships

1. **public-service clarity.** Navigation and content order support broad audiences and urgent contexts.
2. **responsive editorial grid.** Story prominence changes without breaking reading sequence.
3. **media diversity.** Text, audio, video, live information, and imagery keep distinct roles.
4. **accessibility as structure.** Semantics, input modes, and legibility shape the system rather than decorate it.

## Public-service clarity in practice

Editorial grid with variable story weight. Navigation and content order support broad audiences and urgent contexts.

Story prominence changes without breaking reading sequence.

Text, audio, video, live information, and imagery keep distinct roles. Semantics, input modes, and legibility shape the system rather than decorate it.

Minimal live-state feedback with reduced-motion support.

## Adaptation rules

Suitable contexts: large public media services, and content platforms balancing breaking information with deep archives.

Preserve: public-service clarity and responsive editorial grid.

Poor fit: small campaign sites that do not need a system for continuous high-volume publishing.

## Failure modes

**Stop 1.** Using equal card grids that erase editorial priority.

**Stop 2.** Treating accessibility as a final contrast check.

**Stop 3.** Letting live or promotional modules interrupt the main reading order.
