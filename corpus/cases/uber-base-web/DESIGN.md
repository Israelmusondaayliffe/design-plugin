## Adaptation rules

Suitable contexts: multi-product platforms requiring themeable components, and transactional systems with many teams and recurring control patterns.

Preserve: themeable primitives and transport-scale state coverage.

Poor fit: single editorial properties where a large component surface adds maintenance without benefit.

## Failure modes

**Stop 1.** Changing component behavior while applying a theme.

**Stop 2.** Using a broad library as permission to place every component on one screen.

**Stop 3.** Mistaking visual neutrality for a complete brand direction.
