# Mozilla Protocol

## Visual thesis

This case treats implementation continuity as the boundary around publishing grammar. The abstract study is modular editorial bands with bold type, one campaign color, and a bounded media feature.

## Signature relationships

| Relationship | Design consequence |
| --- | --- |
| Publishing grammar | Reusable modules support several kinds of public communication. |
| Voice without sameness | Brand character survives without one rigid page template. |
| Editorial range | Long reading, campaigns, and product explanation share compatible foundations. |
| Bounded expression | Color and media can become loud in named roles while utility remains stable. |
| Implementation continuity | Design guidance and front-end components are presented as one working system. |

## Editorial composition and proof

Alternating full-width and reading-width modules. Let publishing grammar set the reading order, then pressure-test implementation continuity in multi-property organizations publishing campaigns and product stories. The source surface is not the target.

## Type, color, and art direction

The type role is distinct display, reading, and utility voices, with implementation continuity as its stress test. The media role is separate product, photography, illustration, and data roles. Destination color should clarify editorial range and preserve publishing grammar.

## Narrative behavior and access

Let voice without sameness govern feedback timing. Light component feedback with no required spectacle.

Test Mozilla Protocol with keyboard, touch, zoom, and reduced motion while users handle browsing and discovery, plus evaluation and conversion. Focus and reading order should reinforce publishing grammar; contrast and non-color cues should protect editorial range. Reject any result that causes this failure: treating every module as interchangeable and losing editorial emphasis.

## Adaptation rules

- Anchor the adaptation in Publishing grammar: reusable modules support several kinds of public communication.
- Multi-property organizations publishing campaigns and product stories supplies the right pressure for Voice without sameness.
- Skip this move in single-screen tools that need dense operational controls more than publishing flexibility.

## Failure modes

1. Treating every module as interchangeable and losing editorial emphasis.
2. Using campaign color across utility content until reading hierarchy collapses.
3. Copying Mozilla voice or imagery instead of adapting the structural grammar.
4. Ignoring localization when display type and modules compress.

## Confidence and unknowns

This case has high evidence confidence. Internal product metrics, unpublished design decisions, and closed-source implementation details were not inspected.
