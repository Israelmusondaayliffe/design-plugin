## Data-first composition in practice

Modular analysis grid around persistent query context. Filters, charts, tables, and query controls stay close to the evidence they affect.

Headings, landmarks, focus, names, and keyboard behavior shape complex pages.

Panels and layout primitives support many data arrangements without inventing new chrome. Technical copy favors clear terms, scan structure, and explicit outcomes.

State announcements and restrained loading feedback.

## Adaptation rules

Suitable contexts: observability, security, and analytics interfaces, and data-heavy tools needing both charts and operational controls.

Preserve: data-first composition and accessible application structure.

Poor fit: low-information marketing pages where dense application framing would add unnecessary machinery.

## Failure modes

**Stop 1.** Using charts without accessible names or tabular alternatives.

**Stop 2.** Fading secondary text until dense pages become unreadable.

**Stop 3.** Separating filters from the data state they control.
