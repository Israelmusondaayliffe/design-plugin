# Apple iPadOS Guidance

## Visual thesis

Touch, keyboard, pointer, pencil, and accessibility input share the same task model. Layouts respond to window size, multitasking, and device orientation.

## Signature relationships

1. **multi-input fluency.** Touch, keyboard, pointer, pencil, and accessibility input share the same task model.
2. **adaptive workspace.** Layouts respond to window size, multitasking, and device orientation.
3. **content over chrome.** Controls remain discoverable without crowding the working canvas.
4. **desktop-class depth.** Productivity features expand while preserving direct manipulation and platform familiarity.

## Adaptation rules

Suitable contexts: tablet productivity and creative applications, and mobile products that must scale into serious workspace use.

Preserve: multi-input fluency and adaptive workspace.

Poor fit: fixed single-column experiences that ignore multitasking and external input.

## Failure modes

**Stop 1.** Designing only for full-screen portrait.

**Stop 2.** Adding pointer-only precision to touch-critical actions.

**Stop 3.** Letting tool chrome overpower the content workspace.
