## Visual thesis

Navigation, data, forms, and actions follow stable hierarchy across large applications. Controls account for loading, validation, selection, warning, and destructive states.

**compact data utility**

## Adaptation rules

1. Suitable contexts: enterprise dashboards with many repeated controls, and administration products requiring broad component and state coverage.
2. Preserve: enterprise information order and component state breadth.
3. Poor fit: brand-first editorial sites that need irregular composition and strong media authorship.

## Failure modes

1. Copying component appearance without the state and information rules.
2. Using high density before the task actually requires it.
3. Treating default tokens as an identity rather than adapting semantic roles.
