# Tamagui Native UI

## Visual thesis

Tokens and component roles stay recognizable across iOS, Android, and web without forcing identical rendering. Layout changes are expressed through a shared system instead of one-off mobile overrides.

## Signature relationships

- **native-web role parity.** Tokens and component roles stay recognizable across iOS, Android, and web without forcing identical rendering.
- **responsive props as grammar.** Layout changes are expressed through a shared system instead of one-off mobile overrides.
- **theme semantics.** Color and space respond to mode and brand while state meaning remains stable.
- **composition before catalog size.** A small set of primitives earns value by forming coherent screens, not by maximizing component count.

## Adaptation rules

1. Suitable contexts: cross-platform mobile products sharing roles across iOS and Android, and React Native teams that also need a related web expression.
2. Preserve: native-web role parity and responsive props as grammar.
3. Poor fit: platform-exclusive products whose value depends on a fully bespoke native control language.

## Failure modes

1. Forcing pixel identity across iOS, Android, and web.
2. Adding responsive exceptions with no token or component rule.
3. Mistaking a large primitive set for a finished product direction.
