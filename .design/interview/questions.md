Record only questions actually asked. Do not duplicate facts already inspected.

## Round 1: Reference foundation

1. Should IBM Carbon be the single forensic reference for rebuilding the Design Reference Library into a working design-intelligence tool, while preserving the library's own identity and content?

## Round 2: Primary product job

1. Should the expanded Library's main new job be helping a designer turn one reference case into an original adaptation brief for their own project?

## Round 3: Data and delivery model

1. Should the first version keep project data only on the user's device, with no accounts or backend? This keeps the benchmark smaller, but it means no automatic cross-device sync or server recovery.

## Round 4: Download audiences

1. Should each case support both a readable brief for people and structured data for software tools?
